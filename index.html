ARES — Autonomous Rescue & Emergency System

My Role: End-to-End System Architecture • Embedded Firmware (C++) • Sensor Fusion (LiDAR/IMU) • Computer Vision Pipeline • Autonomous Navigation

The Problem: Disaster and hazardous environments (collapsed buildings, chemical leaks, subterranean tunnels) require immediate reconnaissance without risking human first responders, operating where GPS is unavailable and wireless communications are severely attenuated.

The Engineering Solution: ARES is a rugged four-wheel-drive autonomous ground vehicle engineered for autonomous reconnaissance. It integrates 360° LiDAR spatial mapping, edge computer vision for thermal/survivor classification, closed-loop PID trajectory control, and self-healing encrypted mesh telemetry.

Embedded Control & OS
STM32F4 primary real-time controller paired with dual ESP32 telemetry co-processors. FreeRTOS deterministic task scheduling with closed-loop PID motor velocity regulation.
Sensors & Spatial Fusion
360° 2D LiDAR for point-cloud obstacle mapping, stereo depth camera for 3D topology, 9-DOF IMU Extended Kalman Filtering (EKF), and ultrasonic proximity failsafes.
AI & Edge Vision Pipeline
Onboard lightweight YOLO + OpenCV pipeline performing real-time victim identification, hazard tagging, and thermal anomaly detection at low latency.
Encrypted Telemetry Mesh
Hardware-accelerated AES-256-GCM encrypted RF & MQTT mesh relay protocol, streaming vital telemetry and video feeds back to base station mission control.
// ARES Autonomous Navigation Control Loop (Embedded C++ / FreeRTOS)
void vNavControlTask(void *pvParams) {
  for(;;) {
    SensorFrame frame = xSensorFusion_Read(LIDAR | IMU | STEREO_DEPTH);
    ObstacleMap map = vComputeObstacleMap(frame);
    TrajectoryCmd cmd = xPathPlanner_AStar(map, CURRENT_POSE, TARGET_WAYPOINT);
    vMotorDriver_SetPWM(cmd.left_pwm, cmd.right_pwm); // Closed-Loop PID
    vTelemetry_TransmitEncrypted(&frame, AES_256_GCM);
    vTaskDelay(pdMS_TO_TICKS(20)); // 50 Hz Deterministic Loop
  }
}
