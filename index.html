ARES (Autonomous Rescue & Emergency System)

My Role: System Architecture • Embedded Firmware (C++) • Sensor Fusion (LiDAR/IMU) • Computer Vision Pipeline • Autonomous Navigation & Telemetry

Autonomous robotic platform designed for hazardous-environment search and rescue, integrating embedded computing, LiDAR, computer vision, sensor fusion, AI-based perception, and wireless communication. Engineered to operate reliably in GPS-denied environments such as structural collapses, subterranean tunnels, and industrial hazard zones.

Embedded Computing & Real-Time Control
Raspberry Pi 5 onboard companion computer paired with STM32F4 real-time microcontroller and dual ESP32 coprocessors. FreeRTOS deterministic task scheduling with closed-loop PID trajectory regulation.
Multi-Modal Sensor Fusion
360° LiDAR spatial mapping, BNO055 9-DOF IMU with Extended Kalman Filtering (EKF), Thermal Camera, stereo depth vision, and environmental/gas sensor arrays for hazard detection.
Edge AI & Computer Vision
Onboard lightweight YOLO + OpenCV pipeline performing real-time survivor detection, obstacle classification, and thermal anomaly localization at low inference latency.
Encrypted Mesh & UAV Telemetry
Hardware-accelerated AES-256-GCM encrypted RF & MQTT mesh relay protocol with Pixhawk telemetry integration for coordinated UGV ground and UAV aerial reconnaissance.
// ARES Autonomous Navigation Control Loop (Embedded C++ / FreeRTOS)
void vNavControlTask(void *pvParams) {
  for(;;) {
    SensorFrame frame = xSensorFusion_Read(LIDAR | BNO055_IMU | THERMAL_CAM);
    ObstacleMap map = vComputeLocalSLAM(frame);
    TrajectoryCmd cmd = xPathPlanner_AStar(map, CURRENT_POSE, TARGET_WAYPOINT);
    vMotorDriver_SetPWM(cmd.left_pwm, cmd.right_pwm); // Closed-Loop PID
    vTelemetry_TransmitEncrypted(&frame, AES_256_GCM);
    vTaskDelay(pdMS_TO_TICKS(20)); // 50 Hz Deterministic Execution
  }
}
